Design review · Telegram Trade Tracker

One system, one way to move around

The app works — parsing is solid, trust tiers are useful, the data is real. What's missing is a shared visual language: the login screen, top bar, tabs and Market Intel menu were each designed separately, so every screen re-teaches the same navigation. This is a concrete proposal for a unified design system and a single-nav layout, with a working mockup below.

01

What's inconsistent today

Pulled directly from templates/login.html and templates/dashboard.html.

SeverityWhereIssueWhy it matters
High login.html vs dashboard.html Login and dashboard don't look like the same product Login uses a plain slate‑to‑navy gradient with a generic Bootstrap card; the dashboard uses an indigo→blue navbar gradient, custom badges, tier colors and hover states. A first‑time user gets no visual preview of the app they're about to enter.
High Navbar + tab row + dropdown Three navigation patterns for one job Top navbar (brand + logout), a horizontal tab row (Overview / Today's calls / Leaderboard / Picks / Paper / Trades), and a "Market Intel" dropdown bolted onto the end of the tab row for four more sections.
Medium Sidebar vs tabs Channel switching and section switching don't share a model The channel list lives in a left sidebar as a scrollable list-group; sections live in tabs above the content. Both are "pick one destination from a list," styled and positioned as if they were unrelated.
Medium Color system Color is used for two unrelated systems at once Indigo/blue means "selected navigation." Green/red means "gain/loss." Amber/purple/teal are spent again on sector tags and the divergence badge. On a dense row all five can appear together with no priority between them.
Medium Per‑tab headers No shared page header pattern Each tab invents its own header row (title + badges + right‑aligned meta, or nothing). Trades shows row count and totals; Leaderboard and Paper Trading show nothing. No consistent read on which filters are shaping the view.
02

Proposed system

A small, named palette and a two‑typeface pairing, applied everywhere instead of invented per‑component.

SwatchTokenHexUsed for
Ink#14162bBody text, headings
Indigo#4338caNavigation, active/selected state — nothing else
Sky#2563ebLinks, secondary accents
Gain#0f7a4ePositive P/L only
Loss#c22a2aNegative P/L only
Amber#a2620b"Watch" tier / caution states
Slate#5b5e76Secondary / muted text
Paper#f5f4fbPage background

Rule going forward: indigo/sky are reserved for navigation and interactive selection. Green/red are reserved for P/L, full stop — sector tags and tiers move to neutral‑tinted badges instead of a saturated fill, so P/L stays the one thing that jumps out on a dense row.

RoleTypefaceSample
DisplayManrope 800Track record · 20paisa.com
Body / UIIBM Plex SansTrust tiers, filters and section text — legible at 13–14px across dense tables.
DataIBM Plex Mono₹12,480.50 · 68% · NIFTY 24800 CE

Plex Mono for every number column (entry, target, SL, P/L, %, dates) — tabular figures line up instead of jittering column‑to‑column the way proportional digits do today.

03

Navigation: collapse three patterns into one

Sections and channels are both "pick a destination" — put them in the same left rail, grouped, instead of splitting the job across a navbar, a tab strip and a dropdown.

JobToday — 3 patternsProposed — 1 pattern
Brand / account Top navbar, gradient background, logout button Stays as a slim top bar — brand left, active filters + avatar right
Core sections Horizontal tab row: Overview / Today's calls / Leaderboard / Picks / Paper / Trades "Sections" group in the left rail — same rows, vertical instead of a wrapping tab strip
Market Intel Hidden behind a dropdown bolted onto the end of the tab row (Congress, Institutional, News, Super Investors) Its own labeled group in the rail — visible, not one extra click away
Channels Separate scrollable sidebar list below everything, own search/sort controls Third rail group, right under Sections — same "pick a destination" interaction, same place
Mobile Navbar collapses independently of the tab row, which just wraps onto more lines Whole rail becomes one slide‑out drawer behind a single menu button

05

Rollout order

PhaseChangeTouchesOutcome
1 Foundation — tokens login.html, dashboard.html <style> Replace the ad‑hoc CSS variables and Bootstrap defaults with the palette and type scale above. No layout changes yet; fixes most of the login/dashboard mismatch on its own.
2 Navigation — unified rail App() + sidebar markup in dashboard.html Merge the navbar, tab strip and Market Intel dropdown into the single grouped rail. Biggest structural change of the four.
3 Page header pattern The Section component and each tab body Give every section the same header: title, active filters as chips, right‑aligned summary — so Leaderboard and Paper Trading get the context row Trades already has.
4 Table & badge pass Trades table, SectorTag, TierBadge Tabular‑nums on every number column, neutral‑tinted sector/tier badges, P/L kept as the one saturated color signal on each row.
Prepared for review — nothing has been changed in the running app yet. Say the word on which phase to start with.
